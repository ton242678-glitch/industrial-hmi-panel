# 工程打开与配置

主工程：[`industrial-panel-demo.xjp`](../engineering/industrial-panel-demo.xjp)。触摸屏型号和分辨率来自工程设置：`TS5-700-E/W/4G`、`800 × 480`。

## 打开方式

1. 将仓库下载为 ZIP 并完整解压，或使用 Git 克隆。
2. 在 TouchWin Pro 中打开 `engineering/industrial-panel-demo.xjp`，保留一个工作副本用于修改。
3. 查看登录页、目录页和各模块页；核对工程中的通信配置、设备型号、变量地址和画面资源。
4. 若需要连接自己的设备，按实际 PLC、站号、接口与接线重新设置通信参数。先在厂商软件中检查并编译工作副本，再进行相应调试。

本仓库聚焦触摸屏方案，未附带整套 PLC 程序。HMI 中的设备地址、变量和操作入口依赖对应控制程序，单独下载触摸屏工程不会自动构成完整产线控制系统。

## 公开副本的处理

- 保留工程画面、变量引用、动作定义、资源引用及内嵌资源文件。
- 预置演示登录口令统一为 `000000`；其他口令字段清空。
- 清除原电脑的绝对路径，移除编辑器锁文件。
- 工程名称与页面抬头统一为“产线触摸屏控制方案”。
- 原工程另行保留，本仓库中的公开副本不会覆盖原件。

大多数界面图片已嵌入工程，归档检查确认原内嵌资源数据完整保留。若厂商软件对外部资源提示重新链接，请在工作副本中处理，避免将个人目录重新写入公开归档。

## 画面组织

登录 → 目录 → 各操作模块；公共导航提供 I/O、报警、运动参数和机械参数入口。手动模块按设备功能划分，自动页面集中显示库位和过程状态。

原工程已由作者完成 TouchWin 编译与硬件验证。本次公开归档记录的是脱敏、结构核对和展示整理，未记录新一轮设备下载。
